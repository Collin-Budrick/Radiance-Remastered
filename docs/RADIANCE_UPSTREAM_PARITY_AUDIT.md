# Radiance Upstream Parity Audit

Baseline: `upstream/main` (`414d8e3`). Local branch: `main` (`8f9bae4`).

P2-A recompute scope: `src/main/resources/radiance.mixins.json` from `414d8e3` versus the current local worktree, plus the current `build.gradle` Java excludes. The file-by-file matrix below is retained for context, but the mixin/exclude data in this leading section is the current authoritative P2 data.

Latest closure pass: renderer-parity mixins were restored only where there is a compile-safe 26.2 target and a lifecycle gate. Block tint emission moved from the obsolete block-model renderer hook into the custom section-builder path, item rendering moved to the 26.2 submit-node layer, and default launches no longer initialize the packaged native renderer just because resources are present. `GLXMixins` is now a lifecycle-gated 26.2 `GlDevice` debug-callback bridge. Cloud encoded-face capture, RenderSystem/default-uniform state capture, render-phase state capture, `GpuBuffer` identity/range-upload/mapped-view mirroring, and `PreparedRenderType.drawFromBuffer(...)` packet capture are active as 26.2 bridges. The render-pass replay bridge now mirrors 26.2 sampler state for supported texture samplers, builds replay-owned format-1 uniform payloads, can fall back to mirrored Java buffer ranges when native frame-local buffer ids are stale, carries packet-local blend/depth/raster state through JNI, and has required-world proof of accepted native `item_cutout`, `entity_cutout`, `entity_cutout_cull`, `eyes`, `entity_translucent`, and `lines` overlay replay. The cloud replay bridge has required-world proof of accepted encoded-cloud overlay replay. Minecraft F2 and OS screenshots now read/capture the native overlay color target so screenshot output matches the window-visible Radiance overlay replay. Old texture-util, abstract-texture, block-model-renderer, and buffer-renderer hook classes remain excluded where their upstream descriptors are obsolete or replaced by dedicated 26.2 bridge classes.

## Closed This Pass

- Block albedo emission now flows through `SectionBuilderMixins` and `PBRVertexConsumer.albedoEmission(float)`, so tinted quads carry mutable emission state without reactivating `BlockModelRendererMixins`; the first positive runtime write logs a one-shot proof marker.
- `ItemRendererMixins` now targets the 26.2 `ItemStackRenderState.LayerRenderState.submit(...)` path and forwards vanilla submit-node item rendering unchanged unless the Radiance renderer lifecycle is active.
- Texture, glyph, shader, particle, entity, fluid, banner, item, and startup mixin sources that could be safely retargeted were compiled and reactivated.
- Cloud encoded faces are captured from the 26.2 cloud mesh path and submitted through a lifecycle-gated native bridge; supported encoded cloud packets now reach the native overlay replay path, while unsupported/failing paths leave vanilla clouds active.
- RenderSystem/default uniform state and `Uniform` metadata now flow through lifecycle-gated state bridges without restoring obsolete private-field shadows.
- Render-phase pipeline state is captured from 26.2 `RenderType.prepare()` / `PreparedRenderType` setup and attached to the draw-packet bridge.
- `GpuDevice.createBuffer(...)`, concrete `GpuBuffer.map(...)`, `GpuBufferSlice.MappedView.close()`, `CommandEncoder.writeToBuffer(...)`, `CommandEncoder.copyToBuffer(...)`, and concrete `GpuBuffer.close()` are observed by lifecycle-gated buffer mirror mixins so draw packets can carry native buffer identity when the Java side has mirrored content for the copied range.
- `PreparedRenderType.drawFromBuffer(...)` is observed by a lifecycle-gated render-pass packet bridge. Unsupported or incomplete packets fall back to vanilla and are null-tolerant. The Java/native replay path now carries `firstIndex`, signed `vertexOffset`/`baseVertex`, `firstInstance`, `instanceCount`, scissor state, packet-local blend/depth/raster state, replay-owned uniform payloads, supported sampler mirroring, and optional mirrored vertex/index payloads; current required-world proof accepted native `minecraft:pipeline/item_cutout`, `minecraft:pipeline/entity_cutout`, `minecraft:pipeline/entity_cutout_cull`, `minecraft:pipeline/eyes`, `minecraft:pipeline/entity_translucent`, and descriptor-correct `minecraft:pipeline/lines` replay packets. Glint and unrelated debug point layouts still fall back per packet with precise reasons.
- Minecraft screenshot capture now uses Radiance's native overlay color target while the renderer lifecycle is active, so F2 captures the same overlay replay layer used for visible clouds/entities in the window.
- `Constants.DrawModes` now maps the 26.2 `DEBUG_LINE_STRIP` topology once. This fixes the runtime `Duplicate key DEBUG_LINE_STRIP` crash exposed by the first required-world packet-capture run.
- `RendererAvailability` now distinguishes packaged resources from native lifecycle ownership: default mode stages resources and keeps safe mixins active, while `radiance.renderer.required=true` owns the native renderer or fails fast if resources are missing.
- `radiance.mixins.json` contains no references to build-excluded or missing mixin sources.
- The upstream access widener was not restored: current 26.2 source either uses public APIs, mixin shadows, or reflection for the remaining private internals, and the current Fabric metadata/build file has no access-widener wiring.
- `UnsafeManager` remains build-excluded because no current code references the `sun.misc.Unsafe` helper.

## Next Safe Restoration Batches

1. Full item geometry parity: the submit-node bridge is active and lifecycle-gated through `ItemSubmitMetadataBridge`. It captures item geometry counts, transform presence, light/overlay, tint count, outline color, display context, and foil/glint state, but keeps vanilla because 26.2 `ItemStackRenderState.LayerRenderState.submit(...)` only forwards pose/display/light/overlay/outline/tints/quads/foilType to `SubmitNodeCollector.submitItem(...)`; it does not expose texture/render-type state or a `VertexConsumer` for PBR glint wrapping. The precise runtime marker is `RADIANCE_ITEM_GLINT_BLOCKED_26_2_SUBMIT_NODE_STATE`. Deeper discovery found a descriptor-correct surface at `ItemFeatureRenderer.getFoilBuffer(RenderType, PoseStack.Pose)`: `ItemFeatureRendererMixins` now observes the returned foil `VertexConsumer` and logs `RADIANCE_ITEM_GLINT_SURFACE_26_2_FEATURE_RENDERER` with the source item `RenderType`, returned consumer class, and whether a special foil decal pose is active. Actual native/PBR glint parity should wrap or replace that consumer before `putBakedQuad(...)`; this pass only records the surface and leaves vanilla unchanged.
2. Render-pass replay parity: the 26.2 packet capture is active and null-tolerant, buffer/shader/uniform identity has a first safe bridge, write-mapped buffer close snapshots and partial CPU-visible buffer ranges are tracked, and Java/native replay now passes indexed draw offsets plus packet-local blend/depth/raster state through to Vulkan. Format-1 `item_cutout`, `entity_cutout`, `entity_cutout_cull`, `eyes`, and `entity_translucent` replay is accepted with packet-local `Projection` and `DynamicTransforms` payloads. Descriptor-correct `minecraft:pipeline/lines` replay is accepted after synthesizing the `Globals.ScreenSize` bytes from the Minecraft window when the 26.2 `Globals` buffer is not mirrored. Full vanilla draw cancellation still needs native/PBR glint wrapping and broader unsupported pipeline coverage.
3. Cloud replay parity: cloud encoded-face capture is active and lifecycle-gated; the supported encoded-cloud packet reaches the native overlay replay path. Vanilla clouds remain active for unsupported/failing native paths.
4. Old GL parity: `GLXMixins` is active as a 26.2 `GlDevice` debug-callback bridge; keep both `TextureUtilMixins` variants and the obsolete `AbstractTextureMixins` excluded until a full `GpuTexture` ownership bridge replaces the remaining GL-id assumptions.
5. Replay interface cleanup: formal 26.2 extension names now exist for future workers. Use `GpuResourceIdentityRegistry` as the Java entry point, `MirroredGpuBuffer` for `GpuBuffer` mirror state, `RenderPipelineMirror` for pipeline/shader/native identity, and `UniformStateSnapshot` for uniform payload/binding state. These names are additive aliases over the existing mirror stores; extend those stores instead of creating new identity registries.
